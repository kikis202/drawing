# Turnaround

A drawing-practice web app. It generates random clean 3D forms built from "perfect additions" and gives you exercises to draw them, from Box basics to Chests and lids. It has shot patterns, drawing aids, and saving.

Live: https://kikis202.github.io/drawing/ (goes live after the first deploy).

## Run

```
npm install
npm run dev
```

Then open http://localhost:5173/drawing/.

## Test

```
npm test          # unit tests
npm run test:e2e  # Playwright end-to-end tests
```
